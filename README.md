   # تطبيق مساعد المعهد الذكي 

  تطبيق مساعد المعهد الذكي هو تطبيق موبايل تم تطويره باستخدام Flutter لخدمة طلاب المعهد وتسهيل وصولهم إلى جميع المعلومات الأكاديمية المتعلقة بهم، مثل متابعة الدرجات والحضور والغياب والتسجيل في الكورسات وتقييمها.
  ملاحظة: هذا التطبيق هو جزء من نظام متكامل لإدارة المعهد يتضمن موقع ويب خاص بالإدارة والمدرسين، بينما هذا المشروع يمثل الجزء الخاص بالطلاب فقط.


  # الهدف من تطبيق الطلاب
  يهدف التطبيق إلى توفير منصة رقمية تساعد الطالب على:
  1- الوصول السريع لمعلوماته الأكاديمية.
  2- متابعة تقدّمه في الكورسات أو الدورات.
  3- تنفيذ العديد من الإجراءات دون الحاجة لمراجعة إدارة المعهد.

  # مميزات التطبيق 
  للطلاب المسجلين:
   تسجيل الدخول باستخدام بيانات الطالب.
   مشاهدة قائمة الكورسات المسجل بها.
   متابعة الدرجات والتقييمات لكل كورس.
   عرض الحضور والغياب بشكل مفصل.
   تعديل البيانات الشخصية.
   تغيير كلمة المرور من داخل التطبيق.
   تقييم الكورس بعد انتهاء الدراسة.
   عرض الإعلانات والأخبار الخاصة بالمعهد.
   -  للزوار:
     1- عرض الكورسات المتاحة
     2- عرض معلومات المدرسين
     3- عرض الإعلانات العامة

      # بنية العمل
     
  يعتمد التطبيق على الاتصال مع RESTful API لجلب البيانات وإرسالها، ويتم تبادل المعلومات بين التطبيق والسيرفر لإدارة:
    - تسجيل الدخول
    - جلب الدرجات
    - الحضور والغياب
    - بيانات الكورسات
    - تحديث الملف الشخصي
    -رفع وتخزين التقييمات


   
   # التقنيات المستخدمة
     Flutter,Dart,Json and Api
